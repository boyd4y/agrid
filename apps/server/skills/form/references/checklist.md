# 表单验收与配置检查

## 字段与填写体验

- 来源字段实际存在，columnId 来自 get_table；字段标签可以不同于列名。
- 必填项仅覆盖提交所需信息；隐藏或只读字段不能承担用户必须填写的输入。
- 日期值为 YYYY-MM-DD，数值使用 number，单选/多选对应真实选项；人员选择来自工作区。
- 分组中的 fieldIds 使用表单返回的真实字段标识，不凭标题猜 ID。
- classic 适合连续查看短表；focus 为一题一屏。主题预设以 set_form_theme schema 为准。
- select display=buttons 等题型设置通过 set_form_field_settings.settings 配置，不改变底层列类型。
- 文件列尊重 file.multiple，文件上传成功与表单提交成功是两个不同结果。

## 配置与真实提交

先 get_view 保留已有布局，再局部修改并重新读取 resolvedFields。set_form_fields 是整体替换，不遗漏要保留的字段；set_form_sections 编排分组，不创建底层列。

预览检查标题、说明、顺序、必填、提交按钮及成功提示。用户需要真实提交验证时，使用 UI 填写明确测试记录，并在表格查询核对值；不能仅凭配置保存成功报告“提交已验证”。工具不提供表单发布、匿名公共链接或外部网站部署承诺。

提交失败先保留填写内容并查看具体校验/保存错误。若记录已经保存而反馈中断，查询目标表核对，不重复提交同一测试记录。完成后说明表单 viewId、目标表、已验证内容和未验证部分。
