# Playbook references

每个 reference 是本技能下的场景资料，不是独立技能。先读 overview，再按 tables、views、agent、automations 搭建；sample-data 默认可选。

| 名称 | 场景与入口 |
| --- | --- |
| real-estate-broker | [房产经纪人演示工作区](real-estate-broker/overview.md) |

新增 reference 时，在 `references/<name>/` 提供 overview.md、tables.md、views.md、agent.md、automations.md、sample-data.md，并在此索引登记。描述字段类型、稳定选项 ID、关联、实际智能体配置、规则触发与动作、样例是否可选及可验证的对话路径；使用现有工具，明确能力缺口，不添加虚构安装接口。核对来源资料，标明虚构样例与外部动作边界。
