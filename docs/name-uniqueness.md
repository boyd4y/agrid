# 表格与字段名称

同一工作区的表格名、同一表格的字段名不允许重复。比较时忽略首尾空白与大小写；不同工作区的表格、不同表格的字段可以同名。记录标题不受此限制。

数据库迁移 `0024_scoped_names.sql` 使用不可延迟的约束触发器执行检查，并用作用域父记录写锁序列化同一范围的检查。直接 SQL、新增、改名、迁移作用域和多条 INSERT 都适用。普通隔离级别下并发同名写入只有一个成功；可重复读的陈旧快照会触发序列化失败，不会保存重复名称。查询使用作用域与规范化名称索引。

已有重复名称原样保留，允许更新说明、宽度等信息；修改成其他名称时仍执行检查。这样迁移不需要删除或擅自重命名历史数据。字段批量写入、类型转换及双向关联创建在同一事务中，任意重名会整体回滚。

应用将这两个已知数据库约束错误转换为 HTTP 409 JSON，显示具体表格/字段重名提示，不暴露 SQL。其他约束保留原有错误处理。

验证用例：`apps/server/test/commands/name-conflicts.test.ts`（直接 SQL、历史重复、并发、可重复读、批量回滚）；`apps/client/test/browser/name-conflicts.mjs`（API 409 与原子性）。只在隔离的 `_agent_test` 数据库运行测试。
