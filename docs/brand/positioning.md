# tabdo 品牌定位与宣传文案

2026-10-13 · 用户确认名称含义，并明确个人和小团队的使用定位。CRM 只是一个案例。

## 定位

**tabdo 是一个 AI 原生工作空间。**

以灵活数据为基础，让 AI 帮人整理信息、安排步骤并动手完成操作。Agent-first 是产品策略；对外使用想法、计划和行动这些日常词语，避免企业流程平台的叙述。

面向个人管理资料与计划，以及小团队组织项目与协作。旅行安排、资料整理、小组项目、客户跟进都可以是案例，任何单个案例都不定义产品品类。

## 名称

**tabdo.ai = Table → Do → AI。**

- Table：灵活数据，承载信息、关系与状态。
- Do：动手执行，让想法产生具体变化和结果。
- AI：组织信息和推进事情的原生方式。

Table 说明底座，不把主宣传限定为多维表格；AI 同时参与整理、设计与实际操作。

## 统一文案

**主 slogan：让想法，动起来。**

**正文：把想做的事告诉 tabdo，让 AI 帮你整理信息、安排步骤并动手完成。你随时可以查看和调整。**

**短介绍：从想法，到行动的 AI 原生工作空间。**

**宣传展开：整理一份资料，安排一次旅行，或推进一个小组项目。把你的想法和已有信息告诉 tabdo，AI 帮你组织成可查看、可调整的计划，再通过具体操作推进下一步。**

**登录：回到你的工作空间，继续让想法落地。**

**注册：给想法一个空间，让 AI 帮你迈出下一步。**

## 表达顺序

想做什么 → 整理已有信息 → 安排步骤并动手执行 → 查看和调整。

表格、表单、看板、自动化与报告是帮助完成这些事情的能力，在需要时具体解释；不作为宣传标题的功能清单。

主文案不使用业务编排、企业流程、竞品风格或“一张表”。技术文档仍准确描述数据结构、技能和工具。避免承诺尚未实现的跨软件集成、网页采集、HTML 定制、Site 或无人监督的全天自主执行。

## 登录页设计

桌面为品牌视觉与认证表单两栏，窄屏突出表单；统一深浅主题、页头品牌与主题切换。移除旧人物和空白纸张插画，使用品牌矢量图表达想法经 AI 组织成资料、计划与可查看结果。

排版用系统无衬线体承担标题和正文，等宽字体只用于 Table → Do → AI 的名称解释。色彩沿用语义主题：背景 #ffffff、正文 #37352f、品牌蓝 #1769b7、弱底色 #f7f6f3、边线 #e3e2de；深色由对应主题变量自动切换。没有新增全局 CSS 或运行时外部字体。
