# 表单设计

先定义谁填写、为什么收集、提交后数据如何使用。把收集过程分为简短连续的步骤，优先保留必要信息；不要直接把表格所有列铺成表单。

字段编排顺序建议：识别信息 → 业务问题 → 补充信息。复杂流程用分组和布局降低一次需要理解的信息量。根据真实填写场景选择移动端友好的标签、输入控件和帮助文案。

完成前阅读 references/checklist.md 核对表单。

先确认数据写入哪张表，用 get_table 获取字段；缺少必要字段时先创建字段。

使用表单工具创建和配置视图。按工具 schema 提供真实 viewId、columnId，设置字段显示、必填、顺序、分组和主题。表单字段对应表格列，不能凭空引用不存在的字段。

保持表单标题、说明和提交按钮简洁。对联系方式、数值和日期使用正确字段类型。不要把运行实现细节写进表单用户文案。

配置后重新读取表单，核对顺序和必填项。按用户需要打开表单预览；保存配置不等于发布或完成真实提交。
